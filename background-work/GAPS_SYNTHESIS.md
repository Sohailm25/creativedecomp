# Gaps Synthesis

This is the short list of thesis-level non-negotiables for the current experiment.

1. The novelty is the connection between creativity steering and SAE-based mechanistic decomposition.
2. The paper must explain why creativity is or is not mechanistically different from simpler behavioral concepts such as refusal and sentiment.
3. A clean descriptive alignment to a creativity direction is not enough; feature interventions must matter.
4. Cross-domain bridge claims require explicit evidence beyond creative-writing style changes.
5. Output-feature filtering is part of the core method, not an optional polish step.
6. Controller-style creativity navigation is extension work unless the base decomposition lane is already solid.
7. MacBook feasibility is part of the story, so the default stack should stay realistic and reproducible.
